Como funciona:

1. Cole o Access Token da conta do Mercado Livre.
2. Clique em "Testar e conectar".
3. O site consultará o seu backend para validar o token.
4. Se estiver válido, a conta será salva neste navegador.
5. Você poderá cadastrar outras contas e alternar entre elas.

O token não fica escrito no código do site e não é colocado na URL.
