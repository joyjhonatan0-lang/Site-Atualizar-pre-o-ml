Entrar no painel

Cadastre Client ID, Client Secret, URL de retorno e o Access Token que você já gerou. Se você também tiver o Refresh Token, informe-o para ativar a renovação automática. Depois de salvar, o painel usará o token guardado no servidor para consultar as APIs do Mercado Livre.

Se você colar também o Refresh Token gerado junto com o Access Token, o servidor poderá renovar o acesso automaticamente.

Por segurança, o token completo permanece no servidor. O painel usa esse acesso automaticamente e o renova com Refresh Token.

O Client Secret é enviado diretamente ao seu servidor Render e não é salvo no localStorage do navegador.

Conhecimento, pesquisa e conteúdo

Agentes de produto

Crie uma base para cada produto. Acrescente informações, organize as ideias no chat e pesquise fontes para melhorar seus anúncios.

Conecte sua conta para carregar os agentes.
Base do produto
Preencha os dados e salve para começar.

Os termos salvos serão combinados com as sugestões da pesquisa, até 80 palavras-chave relevantes.

A pesquisa usa Tavily e a organização usa Cloudflare. Os planos gratuitos têm cotas. A rotina funciona enquanto o servidor estiver ativo e a conta conectada. Escolha a frequência considerando a quantidade de agentes.

Pesquisa, SEO e ficha encontrada
Revise as especificações pesquisadas e marque quais correspondem ao seu produto. Depois, salve o agente.
Consultar pesquisas e dados salvos

O acervo acumula fontes, especificações, palavras-chave e ideias deste produto no banco de dados. Registros iguais não são duplicados. Revise as especificações antes de usar no anúncio.

Chat para organizar as ideias
Chat com Cloudflare: peça para organizar a ficha, acrescentar informações ou sugerir uma abordagem para o anúncio.

A organização aparece primeiro no chat. Use “Aplicar organização” para preencher os campos e salve quando terminar.

Publicação, IA e imagens

Criar anúncios em massa

Envie a foto do produto, gere títulos SEO, descrição, atributos da categoria, 11 imagens do anúncio e acompanhe uma prévia estilo planilha do Mercado Livre antes de publicar.

Verificando modelo de publicação...
1. Produto, foto de referência e geração com IA
A imagem enviada será usada para analisar o produto, sugerir SEO e gerar o pacote com 11 fotos do anúncio.

Escolha um agente para usar a ficha técnica, as informações revisadas e as palavras-chave salvas.

Pode enviar até 8 imagens. A primeira foto será a principal para análise e geração.
Configuração comercial
Se o Mercado Livre exigir frete grátis para esse preço/categoria, o servidor ajusta automaticamente.
Busca focada em SEO e intenção de compra. Pesquisa na internet é opcional no servidor.
2. Categorias do anúncio
Escolha uma ou várias categorias. A IA sugere e preenche automaticamente as características exigidas por cada uma.
3. Variações
Cada título/família receberá todas as variações configuradas abaixo. No modelo User Products, cada variação vira um item da mesma família, com tamanho, cor e demais atributos próprios.
Cada título receberá todas as variações configuradas. O limite final também depende da categoria do Mercado Livre.
Cole somente o código do guia. O painel busca as linhas do guia e associa automaticamente cada tamanho ao SIZE_GRID_ROW_ID correto.
Informe o código do guia. Depois, os IDs das linhas serão preenchidos automaticamente pelas numerações das variações.
Atributos que diferenciam as variações
Os atributos permitidos pela categoria são carregados automaticamente. Marque, por exemplo, Tamanho, Cor, Desenho do tecido ou outro campo que realmente muda entre as variações.
Preenchimento individual
Cada variação tem campos próprios. Os mesmos 7 valores, por exemplo, serão repetidos em cada título/família que você gerar.
4. Fotos do anúncio geradas
A capa sempre é gerada com fundo branco. As 11 imagens são geradas pela Cloudflare Workers AI em 1080 x 1080; as demais são feitas para aplicação, uso, benefícios, diferenciais, ficha técnica e contexto de uso do produto.
Aguardando geração das imagens. 0/11
Primeiro o painel usa a Cloudflare Workers AI para gerar as imagens. Se a cota diária terminar, ele mantém o que já foi gerado e completa o restante com um kit visual baseado nas fotos reais enviadas.
Se você preencher este campo, estas URLs serão usadas no anúncio no lugar das imagens geradas. Aceita uma URL por linha ou o formato [url1,url2,url3]. As URLs precisam ser públicas e acessíveis pelo Mercado Livre.
Nenhuma URL manual informada; o painel usará as imagens geradas.
5. Títulos / nomes de família
Um por linha, sempre limitado a 60 caracteres e com foco em SEO e conversão.
Os termos pesquisados entram nos próximos lotes. As fontes aparecem junto às palavras-chave.

Até 5.000 por lote. Se interromper, clique em Gerar para continuar os títulos desta sessão.

6. Descrição
Descrição profissional robusta, detalhada, clara e focada em conversão, aplicação e benefícios do produto.
7. Prévia estilo planilha do Mercado Livre
Conforme você preenche título, preço, estoque, SKU, categorias e imagens, a prévia abaixo é atualizada automaticamente.
Categoria Título / família Variação Condição Preço Estoque SKU Atributos URLs fotos
8. Validar e publicar
Valide nas categorias escolhidas antes de iniciar a criação em massa.
